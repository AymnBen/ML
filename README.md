# 📊 Machine Learning Notebooks

Ce dépôt contient plusieurs travaux pratiques et mini-projets en **Machine Learning** réalisés avec **Python** et **Scikit-learn**.

L'objectif est d'expérimenter différents algorithmes de classification et de manipulation de données à travers des notebooks Jupyter.

---

# 📁 Contenu du projet

## 📓 Notebooks

- `td1.ipynb` → Introduction au Machine Learning  
- `td2.ipynb` → Détection de spam avec l'algorithme **Naive Bayes**
- `TP_ML_4_Mini_Projets_Complet.ipynb` → Implémentation et tests de plusieurs algorithmes de Machine Learning

Les algorithmes utilisés dans ce notebook :

- K-Nearest Neighbors (KNN)
- Arbre de Décision
- Naive Bayes
- Support Vector Machine (SVM)

---

## 📊 Jeux de données

Les datasets utilisés dans les mini projets :

- `mini_projet_1_clients.csv` → Dataset de clients
- `mini_projet_2_etudiants.csv` → Dataset d'étudiants
- `mini_projet_3_spam.csv` → Dataset pour la détection de spam
- `mini_projet_4_fruits.csv` → Dataset pour la classification de fruits

Ce projet a pour objectif de :

# 🚀 Exemple : Détection de Spam

Le modèle de détection de spam fonctionne en plusieurs étapes :

1. Transformation du texte en vecteurs numériques avec **CountVectorizer**
2. Entraînement d'un modèle **Naive Bayes**
